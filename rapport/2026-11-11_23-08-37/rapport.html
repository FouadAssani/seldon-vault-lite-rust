Notes & caveats

  • Fast suite parity skip: SELDON_SKIP_MODEL_PARITY=1 makes real-model parity tests return early; they were replayed separately and all pass.
  • Network isolation: disabled because sandbox-exec was unavailable; do not claim an isolated offline run.
  • Gatekeeper: the ad-hoc build is rejected by spctl; expected for the local-use artifact.
  • Attempt 1: all lifecycle checks passed, but the harness exited 1 at the final report copy because the --report path was relative. Attempt 2 used an absolute path and passed; the attempt 1 log is retained as logs/release-e2e-attempt1.log.
  • Memory: the harness max RSS is higher than individual embeddings because the HTTP server holds text, image, and audio weights in one process.
  • Image/audio performance: the towers remain scalar correctness baselines; the 70-token image and 100 ms audio measurements are not optimized results.

Reproduce this run

cd /Users/fouadassani/projets/seldon-vault-lite-rust

# Fast suite (includes the release E2E lifecycle test)
SELDON_SKIP_MODEL_PARITY=1 cargo test

# Release-mode text benchmark
cargo test --release --test text_bench -- --ignored --nocapture

# Standalone embedded embeddings
BIN=target/embedded-full/aarch64-apple-darwin/release/seldon-vault-lite
"$BIN" embed --text "What causes the northern lights?" --dim 768
"$BIN" embed --image fixtures/media/quadrants_16x16.png --dim 768 --vision-tokens 70
"$BIN" embed --audio fixtures/media/audio/short_tone_100ms.wav --dim 768

# Full release E2E harness (absolute --report path required)
scripts/release_e2e.sh \
  --binary "$BIN" \
  --report "$PWD/rapport/2026-11-11_23-08-37/release-e2e-report.json"

# Frozen-model parity replay
cargo test --release --test text_embeddings real_model_parity -- --nocapture
cargo test --release --test image_embeddings image_embedding_matches_the_official_reference -- --nocapture
cargo test --release --test audio_embeddings audio_embedding_matches_the_official_reference -- --nocapture
