## Manifest contents

`manifest.json` is the versioned record of the frozen model:

- schema version;
- model id `google/embeddinggemma-2`;
- exact revision `f9972ac22e696a105c482202646979e33e4b5a1e`;
- source URL, freeze date, and license;
- every file in the repository tree with size, SHA-256, role, and a
  `committed: false` marker;
- tokenizer inventory: vocabulary size, merge count, byte fallback,
  normalizer, pre-tokenizer, post-processor, added tokens, and special ids;
- text configuration: layers, hidden size, embedding dimension, heads,
  sliding window, maximum positions, RMSNorm epsilon, activation, layer types,
  per-layer overrides, and RoPE parameters;
- official prompt map;
- SHA-256 of the committed fixtures.

## Text golden fixture

`text_golden.json` (schema version 2) was generated outside the product with
Transformers 5.22.2, PyTorch 2.15.0 CPU, and the frozen model in float32.

It contains eight cases:

| Case | Prompt | Text |
|---|---|---|
| `en-query` | SearchQuery | What causes the northern lights? |
| `en-document` | Document | The northern lights are caused by charged particles from the sun. |
| `fr-query` | SearchQuery | Bonjour, le monde ! Comment allez-vous ? |
| `code-query` | CodeRetrieval | `fn main() { println!("hello"); }` |
| `empty-query` | SearchQuery | empty string |
| `unicode-similarity` | SentenceSimilarity | `café 😀 日本語` |
| `classification` | Classification | This is a positive review. |
| `clustering` | Clustering | The cat sat on the mat. |

Each case records the prompt name, prefix, text, official token ids, and
normalized embeddings at 768, 512, 256, and 128 dimensions.

The layer probe uses the SearchQuery prefix and the text `hello`. It records
the scaled embedding output, all 24 layer outputs, and the final projected
state, as means and last-token vectors.

## Tiny official model

`tiny_text/` is a complete EmbeddingGemma 2 text model generated with the
official Transformers code. It has:

- 3 layers: two sliding-attention layers and one full-attention layer;
- hidden size 16, embedding dimension 8, intermediate size 32;
- 2 query heads and 1 key/value head; sliding head dimension 8, full head
  dimension 16;
- PLE dimension 8;
- sliding window radius 2;
- RoPE theta 10,000 for sliding and 1,000,000 for full;
- 56 tensors and 10,315 parameters.

`golden.json` records three token-id sequences with the scaled embedding
output, every layer output, the final projected state, and the normalized
embedding. This fixture exercises sliding and full attention, grouped-query
attention, PLE, two RoPE bases, and Matryoshka truncation without the 1.5 GB
weights. It is generated by the official implementation, not by the product.

## Model files

Model files are development assets and are not committed. They live in:

```text
.model-cache/<revision>/
```

The directory is ignored by Git. Fetch a file with:

```bash
REV=f9972ac22e696a105c482202646979e33e4b5a1e
curl -sSL "https://huggingface.co/google/embeddinggemma-2/resolve/$REV/config.json" \
  -o .model-cache/$REV/config.json
```

The weights file is about 1.5 GB. Its SHA-256 in the manifest is the Hugging
Face LFS object id:

`197a32965d4b1105faf060417baa899e193fb73cd401f42ec9295234d5553d79`

The text parity test verifies this fingerprint before running. The file is not
needed for the tiny fixture.
