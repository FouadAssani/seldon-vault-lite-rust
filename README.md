# seldon-vault-lite-rust

## Skills Rust (DSH)

Les skills du dépôt [actionbook/rust-skills](https://github.com/actionbook/rust-skills) sont installés dans `.dsh/skills/` (version 2.0.9, commit `5c40d3a`).

Mise à jour :

```bash
git clone --depth 1 https://github.com/actionbook/rust-skills.git /tmp/rust-skills
cp -R /tmp/rust-skills/skills/. .dsh/skills/
```
